NEW metrics to compute at end of each iteration (ESSENTIAL)
lat_MA20
Mean of the rolling buffer of average_latency_iter (use whatever is available until it fills 20).

gap_MA20 (aka (lat-greedy)_MA20)
Mean of the rolling buffer of (average_latency_iter − greedy_latency_iter).

CP_before_med
Median of all valid cp_before values for steps in this iteration.

CP_after_med
Median of all valid cp_after values for steps in this iteration. Expect CP_after_med ≤ CP_before_med + small_threshold.

CP_drop_med
Median of (cp_before − cp_after) over steps that have both values.

shape_base_ratio_med
Median over steps of
abs(shaping_contribution) / (abs(base_step_score) + small_threshold)
(compute only where a base score exists).

clamp_hit_frac
Fraction of steps where final_step_score is within small_threshold of either clamp bound.

cp_violation_count
Count of steps where cp_after > cp_before + small_threshold.

Rules:

If a required array is empty this iteration, emit nan for its metric (or 0 for counts).

Use the same time unit everywhere (e.g., ms).

Exclude non-finite values from medians.
