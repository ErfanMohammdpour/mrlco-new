## پروژه ۱ — عنوان

```text
طراحی و ارزیابی چارچوب Graph2Seq و یادگیری تقویتی فرا (Meta-RL) برای آفلودینگ وظایف DAG در محاسبات لبه موبایل (MEC)
```

## پروژه ۱ — تعریف کوتاه

```text
این پروژه یک چارچوب نرم‌افزاری برای آفلودینگ وظایف وابسته در قالب DAG در محیط Mobile Edge Computing (MEC) طراحی و ارزیابی می‌کند. در این مسئله، هر وظیفه می‌تواند یا روی دستگاه محلی (Local) اجرا شود یا به سرور MEC ارسال شود. برای نمایش ساختار وابستگی وظایف از Graph2Seq encoder استفاده می‌شود و سپس یک رمزگشا، دنباله تصمیم‌های آفلودینگ را تولید می‌کند. سیاست تصمیم‌گیری با Meta-RL و با استفاده از PPO و Reptile آموزش داده می‌شود تا بتواند روی توزیع‌های جدید گراف با چند مرحله تنظیم، سریع‌تر تطبیق پیدا کند. تمرکز اصلی پروژه، بررسی معماری رمزگشا، پارامترهای آموزش و پایداری همگرایی در هدف کاهش زمان اتمام کل برنامه (makespan) است.
```

## پروژه ۱ — روند اجرا

```text
۱) مطالعه مفاهیم MEC، زمان‌بندی DAG، Graph2Seq، PPO و Reptile.
۲) آماده‌سازی شبیه‌ساز آفلودینگ دوحالته Local/MEC.
۳) استخراج ویژگی از گراف‌های DAG و تولید ورودی مناسب برای Graph2Seq.
۴) پیاده‌سازی رمزگذار Graph2Seq و رمزگشا.
۵) آموزش سیاست با Meta-RL و ذخیره مدل آموزش‌دیده.
۶) ارزیابی روی توزیع‌های مختلف گراف و مقایسه با Greedy.
۷) تحلیل نتایج، رسم نمودار همگرایی و تهیه گزارش نهایی.
```

## پروژه ۱ — خروجی

```text
۱) گزارش پروژه حداقل ۸۰ صفحه.
۲) کد قابل اجرا برای آموزش و ارزیابی سیاست آفلودینگ.
۳) مدل آموزش‌دیده و فایل‌های لاگ.
۴) نمودار همگرایی makespan در طول آموزش یا تنظیم.
۵) جدول مقایسه روش پیشنهادی با Greedy و نسخه‌های مختلف رمزگشا.
۶) فایل راهنمای اجرای آزمایش‌ها.
۷) ارائه شفاهی ۱۵ تا ۲۰ دقیقه‌ای برای دفاع.
```

## پروژه ۲ — عنوان

```text
طراحی و ارزیابی چارچوب آفلودینگ آگاه از انرژی برای وظایف DAG در MEC با قابلیت Vehicle-to-Vehicle (V2V) و یادگیری تقویتی فرا (Meta-RL)
```

## پروژه ۲ — تعریف کوتاه

```text
این پروژه یک چارچوب نرم‌افزاری برای آفلودینگ وظایف وابسته در قالب DAG در محیط Mobile Edge Computing (MEC) با قابلیت Vehicle-to-Vehicle (V2V) طراحی و ارزیابی می‌کند. در این مسئله، هر وظیفه می‌تواند روی دستگاه محلی (Local)، سرور MEC یا کمک‌پرداز Vehicle-to-Vehicle (V2V) اجرا شود. شبیه‌ساز پروژه محدودیت half-duplex در کانال V2V و همچنین مصرف انرژی را در نظر می‌گیرد. سیاست تصمیم‌گیری با Graph2Seq encoder، رمزگشا و Meta-RL شامل PPO و Reptile آموزش داده می‌شود. هدف پروژه، کاهش همزمان زمان اتمام برنامه (makespan) و مصرف انرژی و مقایسه عملکرد روش پیشنهادی با standard DRL، Greedy و نسخه بدون V2V است.
```

## پروژه ۲ — روند اجرا

```text
۱) مطالعه MEC، Vehicle-to-Vehicle (V2V)، مدل انرژی و Meta-RL.
۲) تکمیل شبیه‌ساز با سه گزینه اجرا: Local، MEC و V2V.
۳) پیاده‌سازی محدودیت half-duplex در زمان‌بندی V2V.
۴) افزودن مدل انرژی و پاداش ترکیبی تأخیر–انرژی.
۵) اتصال سیاست Graph2Seq + Meta-RL به شبیه‌ساز.
۶) آموزش و ارزیابی روی گراف‌های DAG.
۷) مقایسه با standard DRL، Greedy، MRLCO-style و نسخه بدون V2V.
۸) تحلیل رفتار سیاست و تهیه گزارش نهایی.
```

## پروژه ۲ — خروجی

```text
۱) گزارش پروژه حداقل ۸۰ صفحه.
۲) کد قابل اجرا برای شبیه‌ساز، آموزش و ارزیابی.
۳) مدل آموزش‌دیده و فایل‌های لاگ.
۴) جدول مقایسه روش پیشنهادی با standard DRL، Greedy، MRLCO-style و نسخه بدون V2V.
۵) نمودار همگرایی تأخیر و انرژی.
۶) نمودار توزیع تصمیم‌ها بین Local، MEC و V2V.
۷) پیوست معادلات زمان‌بندی half-duplex V2V.
۸) ارائه شفاهی ۱۵ تا ۲۰ دقیقه‌ای برای دفاع.
```
